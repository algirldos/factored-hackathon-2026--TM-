10-Day Sprint - AI-First Banking Customer Service

The Challenge:
Build An AI-First Banking Agent
Don’t build a chatbot, build a customer-service system
END-TO-END WORKING PROTOTYPE
TASK SELECTION
Build a fully functional production-ready prototype
One Focused Banking Workflow
capable of handling complex user interactions beyond
a surface-level demo
1. Account / Payment Inquiries
2. Card Support
MULTILINGUAL SUPPORT REQUIRED
3. Transaction Disputes
4. Credit-Product Info & Eligibility
Demonstrate robust customer service interactions in
both Spanish and Portuguese to serve LATAM
banking needs

SYSTEM GOALS & BEHAVIOR
What Are We Looking For?
The system should be able to: Understand → Decide → Act → Verify → Escalate
MINIMUM REQUIREMENTS
● Maintain conversational context ● Execute appropriate workflows
● Clarify ambiguous requests ● Verify that actions actually happened
● Retrieve trusted information ● Know when NOT to act
● Use tools securely ● Hand off to a human when needed
Key idea: AI should not be autonomous just because it can be
Normal Case Ambiguous / Unsupported Human-Required
Automated Resolution Clarification or Abstention Safe Escalation
Handles policy-compliant Asks clarifying questions or Executes a structured handoff to
automated resolution, verified practices safe policy human representatives,
account queries, and authorized abstention when handling transferring verified facts and
self-service transactions missing parameters or open questions without dumping
seamlessly unsupported banking requests raw transcripts

EVALUATION & RIGOR
Prove It Works
Baseline → Proposed System → Held-out Evaluation
TECHNICAL RIGOR KEY METRICS TO MEASURE
● Data Quality & Contracts: Strict input schema ● Safe Automated Resolution
enforcement
● Unsafe Outcomes
● Reproducible Preparation: Deterministic
● Cost Efficiency
pipeline execution
● Valid Labels: Grounded relevance judgments
& ground truth
● Leakage Prevention: Strict train/eval set
isolation
● Appropriate Split: Realistic held-out test
distributions
● Learned Component: Benchmark against a
baseline model
